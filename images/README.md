# images/

把实拍照片放在这里（README 顶部的「实拍照片」一节会引用）：

| 文件名 | 建议内容 |
|---|---|
| `setup-1.jpg` | LCD 正常显示温湿度 / 光照 / 传感器状态 |
| `setup-2.jpg` | 越界时的整屏红色闪烁报警（蜂鸣器同步） |
| `setup-3.jpg` | 接线全貌（STM32 精英版 + ESP8266 + DHT11/SHT30） |

放好后，把仓库根目录 `README.md` 里「实拍照片」一节中被注释掉的 `<img>` 标签取消注释即可。

建议：宽度 1000–1600 px、单张 < 500 KB（GitHub 上直接显示，也不至于让仓库变胖）。
